---
description: When developer is developing a new feature and the project has some kind of a specification writing library installed (i.e. OpenSpec, SpecKit, BMAD).
---

Start the workflow of the specification writing library. Start from the first step and continue to the end. Try to improve vague ideas by relentlessly "grilling" the user, interviewing him and asking questions. While asking questions, whenever possible, offer a prompt (use the AskUserQuestion tool).
