---
description: Proofread and improve English text written by the user, from a single sentence to a longer document. Use when the user asks to proofread, fix grammar, check their English, improve wording, or points to a text or file to be edited.
---

- If the input is part of a longer text, read the whole text to get an idea of the writing style.
- Keep style changes to a minimum.
- Fix grammar mistakes.
- Flag strange word usage or sentence structures.
- Make all the changes right away. I usually check what was changed through the git diff.
- If the text is entered directly into the prompt (not in a file), return only the improved text, with no comments or explanations.
